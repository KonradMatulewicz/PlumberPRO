- [ ] GitHub repo with all code, documented (README, docstrings where non-obvious)
- [ ] Repo shared with GitHub account `quantic-grader`
- [ ] README links: deployed app, task board, design & testing doc, presentation video
- [ ] Deployed web app on free tier (Render), works from a cold start
- [ ] Task board up to date: all stories Done or explicitly moved to future work
- [ ] Design & testing doc: architecture + patterns + reasons, technologies + reasons,

- [ ] Initiative beyond minimum: ML model, RAG eval, prompt-injection tests, DAST, perf SLOs,
      observability, cost analysis
