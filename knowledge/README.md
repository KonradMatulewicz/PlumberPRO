# Copilot knowledge base (RAG corpus)
- `runbooks/*.md` — one runbook per incident type (volume drop, late upstream, schema change,
  failed load, duplicate rows, credentials expired, ...). Sections: Symptoms, Likely causes,
  Diagnosis steps, Fix, Prevention (suggested data-quality test).
- `incidents/*.md` — resolved historical incidents (generated by the simulator, synthetic).
All content is synthetic and written for this project.
